# Chrono Trigger — русский перевод для Switch (ct_nx)

Полный русский перевод Chrono Trigger для порта [ct_nx](https://github.com/NaGaa95/ct_nx) на Nintendo Switch. Мод заменяет английский текст игры и рассчитан только на управление с геймпада.

Неофициальный фанатский перевод. Перевод: dpadninja, выполнен с помощью Claude (Anthropic).

## Установка

Порт ct_nx должен быть уже установлен и запускаться: в `/switch/ct/` лежат `libchrono.so`, `libc++_shared.so` и `assets/` из `.apk` игры.

1. Скачайте `ct_russian_vX.Y.Z.ctp` со страницы релиза.
2. Скопируйте его в `/switch/ct/mods/`. Если папки нет, создайте её.
3. Уберите из `mods/` другие текстовые моды, например английский патч кнопок, собранный `tools/generate_text_ctp.py` из ct_nx. Они меняют те же файлы, а подписи под кнопки в этом моде уже есть.
4. В `/switch/ct/config.ini` поставьте:
   ```ini
   language = en
   ```
   Подойдёт и `default`, если системный язык консоли английский.
5. Запустите игру. При первом запуске после изменений в `mods/` ненадолго появится экран «Caching mods…».

Чтобы обновить мод, замените файл в `mods/` на новую версию.

## Если что-то не так

- **Текст английский.** Проверьте `language` в `config.ini` и что файл лежит в папке модов (её путь задаётся параметром `mods_dir`).
- **Вместо букв квадраты.** В шрифте нет кириллицы. Укажите шрифт с кириллицей в параметре `game_font_path` в `config.ini`.
- **Подробности.** Смотрите `debug.log` в `/switch/ct/`.

## Сборка из исходников

Нужен Python 3.13+.

```bash
python3 tools/build_ctp.py
```

Мод собирается в `build/ct_russian.ctp`. Если рядом лежат оригинальные файлы игры (`original/Localize/`, в репозиторий не входят), скрипт сначала проверяет тексты (`tools/check.py`). Релиз публикуется автоматически при пуше тега вида `v1.0.0`; проверку перед тегом запускайте локально.
